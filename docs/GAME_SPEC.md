# 게임 화면 및 그리드 규격

현재 A/B 공통 작업 규격입니다. 변경하려면 A와 B가 먼저 합의합니다.

| 항목            | 값                         |
| --------------- | -------------------------- |
| 기준 화면       | 960×540, 16:9              |
| 타일 크기       | 32×32 px                   |
| 전체 타일맵     | 챕터별 가변                |
| 외곽 벽         | 상하좌우 각 1타일          |
| 플레이 영역     | 전체 크기에서 외곽 벽 제외 |
| 렌더링          | Pixel Art, 정수 좌표       |
| 이동            | 상하좌우 한 칸씩           |
| 기본 입력       | 방향키 또는 WASD           |
| 상호작용        | Z                          |
| RESET           | R                          |
| Chapter Restart | C                          |
| 완료 후 진행    | Enter                      |

## 아트 전달 규칙

- 캐릭터와 오브젝트는 32px 그리드에 맞춥니다.
- 캐릭터 이미지가 한 타일보다 커도 발 위치 기준 충돌 영역은 한 타일입니다.
- 타일셋은 Tiled에서 사용할 수 있도록 타일 사이 여백 없이 제작합니다.
- 원본 작업 파일과 게임용 내보내기 파일을 구분합니다.
- 외부 에셋은 출처와 상업 이용 가능 여부를 함께 기록합니다.

## 맵 좌표 규칙

- 전체 맵 좌표는 좌측 상단 `(0, 0)`부터 우측 하단 `(width - 1, height - 1)`까지입니다.
- 기본 외곽 벽은 `x = 0`, `x = width - 1`, `y = 0`, `y = height - 1`에 배치합니다.
- 기본 이동 공간은 `x = 1..width - 2`, `y = 1..height - 2`입니다.
- Chapter 1은 `12×10`이며 이후 챕터는 퍼즐 규모에 따라 더 큰 크기를 사용할 수 있습니다.
- 카메라 이동을 사용하지 않는 레벨은 HUD를 포함한 960×540 화면 안에 전체 맵이 보여야 합니다.
- HUD 안전 영역보다 큰 맵은 Player 추적 카메라를 사용하며 조작·RESET·시계 HUD는 화면에 고정합니다.
- 방 전체는 960×540 화면 중앙에 배치합니다.
- 타이틀, 대화, 컷신은 맵 좌표가 아닌 16:9 화면 좌표를 사용합니다.
- 초기에는 벽이 실제 타일을 차지하며, 향후 아트 레이어와 충돌 데이터는 분리할 수 있습니다.

## 레벨 데이터

레벨은 Tiled JSON으로 관리하며 런타임 로더의 검증을 통과해야 게임에서 사용합니다. 레이어·오브젝트 Class·Custom Property 규칙은 [레벨 데이터 기술 규격](./LEVEL_SCHEMA.md)을 따릅니다.
