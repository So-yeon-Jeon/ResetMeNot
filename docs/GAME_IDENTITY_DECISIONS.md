# Reset Me Not 고유 규칙 결정서

이 문서는 A와 B가 합의한 Reset Me Not 고유 규칙의 기준입니다. Notion의 `최종 결정`을 우선하며, 취소선으로 철회된 내용은 포함하지 않습니다.

## 핵심 정의

```text
Echo → RESET 순간 사람의 상태를 공간에 남긴다.
Memory Object → 지정된 물건의 상태를 시간에 남긴다.
```

Echo는 이전 Run의 이동 경로를 재생하는 존재가 아닙니다. RESET 순간 Player의 상태가 해당 위치에 고정된 시간의 잔상입니다.

## 1. Memory Object

**상태: ✅ 확정**

- 오브젝트 전체가 아니라 `persistentFields`에 지정된 속성만 기억합니다.
- 기본 지원 속성은 `position`, `active/state`, `broken`으로 제한합니다.
- `collected` 같은 소유권·인벤토리 상태는 기본적으로 기억하지 않으며 필요한 레벨에서만 예외로 허용합니다.
- 일반 RESET에는 지정된 속성만 유지하고, Chapter Restart에는 현재 챕터의 퍼즐 상태를 초기화합니다.
- Memory Object 여부는 최초 발견 전까지 숨깁니다.
- 최초 발견 이후에는 Gold 계열 시각 언어를 일관되게 사용합니다.

**결정 이유:** 전체 상태를 유지할 때 생기는 예외를 줄이고 속성 단위로 예측 가능한 퍼즐을 설계하기 위함입니다. Chapter 1의 열쇠는 `position`만 기억하면 표현할 수 있습니다.

## 2. Echo 생성·누적·종료

**상태: ✅ 확정**

- Player가 행동한 Run에서 RESET하면 Echo를 하나 생성합니다.
- 이동이나 상호작용이 전혀 없는 빈 Run은 Echo를 생성하지 않습니다.
- Echo 최대 수는 퍼즐 또는 챕터의 `echoLimit`으로 관리합니다.
- Echo는 RESET 순간 Player의 위치와 방향에 생성됩니다.
- 생성 이후 이동하지 않으며 위치와 방향을 계속 유지합니다.
- 다음 RESET에서도 기존 Echo는 동일한 위치에 남습니다.
- Chapter Restart 시 모든 Echo를 제거합니다.
- Echo 행동 타임라인과 이동 경로 재생은 사용하지 않습니다.

**결정 이유:** 사람의 상태를 공간에 남긴다는 핵심 개념을 단순하고 직관적으로 전달하기 위함입니다.

## 3. Echo가 할 수 있는 행동

**상태: ✅ 확정**

Echo는 RESET 순간 유지 중이던 허용 상호작용을 고정된 위치에서 계속 유지할 수 있습니다.

| 행동                 | 허용   | 규칙                               |
| -------------------- | ------ | ---------------------------------- |
| 압력 스위치 유지     | 예     | Echo가 생성된 타일을 계속 점유     |
| 레버 상태 유지       | 예     | 레벨에서 Echo를 허용한 레버만 가능 |
| Memory Object 변경   | 조건부 | 레벨에서 Echo를 허용한 경우만 가능 |
| 상자 밀기            | 아니오 | Echo는 생성 이후 이동하지 않음     |
| 열쇠 획득·사용       | 아니오 | Echo는 소유권을 갖지 않음          |
| 스토리 오브젝트 조사 | 아니오 | 현재 Player만 가능                 |
| 대화·컷신 시작       | 아니오 | 현재 Player만 가능                 |
| 출구·챕터 완료       | 아니오 | 현재 Player만 가능                 |

- Player와 Echo, Echo와 Echo는 서로 충돌하지 않으며 같은 타일에 있을 수 있습니다.
- Echo는 움직이는 오브젝트와 능동적으로 상호작용하지 않습니다.

## 4. Memory Object와 Echo

**상태: ✅ 확정**

- Echo도 레벨에서 명시적으로 허용한 Memory Object에 영향을 줄 수 있습니다.
- Player와 Echo의 상태 변경에는 동일한 `persistentFields` 규칙을 적용합니다.
- Echo가 만든 변화도 해당 속성이 `persistentFields`에 포함되면 RESET 후 유지됩니다.
- 실패한 상호작용은 자동으로 보정하지 않습니다.
- Echo는 고정된 잔상이므로 시간에 따라 새 행동을 실행하거나 이동형 오브젝트를 추적하지 않습니다.

## 5. RESET 한도

**상태: 🟡 방향 확정, 챕터별 숫자 미정**

- 모든 챕터에 서로 다른 RESET 제한을 둡니다.
- 제한의 목적은 Echo 최대 수와 퍼즐 복잡도를 통제하는 것입니다.
- RESET을 모두 사용해도 강제로 재시작하지 않습니다.
- 한도 소진 후 RESET만 사용할 수 없고 현재 상태의 이동·조사·상호작용은 계속할 수 있습니다.
- Player는 메뉴에서 Chapter Restart를 직접 선택할 수 있습니다.
- RESET 잔여량은 표시가 필요한 챕터에서만 HUD에 보여줍니다.
- Chapter 2는 RESET 1회 제한 후보이며 HUD는 생략할 수 있습니다.
- Chapter 4와 Final의 RESET 횟수는 퍼즐 상태와 별도로 World Memory에도 기록합니다.

## 6. Puzzle State와 World Memory

**상태: ✅ 확정**

### Puzzle State

- 현재 챕터 안에서만 사용합니다.
- Chapter Restart 시 초기화합니다.
- 상자 위치, 스위치 상태, Memory Object 상태, 현재 Echo 목록을 포함합니다.

### World Memory

- 게임 전체에서 유지합니다.
- 전체 RESET 횟수와 특정 중요 RESET을 기록합니다.
- 주요 행동·선택과 엔딩 삽화에 반영할 이벤트를 기록합니다.
- Chapter 4의 이상 현상 조건에 사용합니다.

**결정 이유:** 퍼즐은 안전하게 다시 시작할 수 있게 하면서도 세계와 책이 플레이어의 반복을 기억한다는 반전을 유지하기 위함입니다.

## 7. Final — LET TIME GO

**상태: ✅ 확정**

- 마지막 방에는 앞으로 흐르는 실제 시계가 있습니다.
- 문에는 “다음 종이 울릴 때 문이 열린다”는 의미의 힌트를 제공합니다.
- 방 진입 시 시계는 종이 울리기 직전 시각에서 시작합니다. 예: `11:59:50`.
- RESET하면 Player는 시작 위치로 돌아가고 Echo가 남으며 시계도 시작 시각으로 돌아갑니다.
- RESET은 마지막까지 활성 상태이며 Player가 스스로 사용하지 않기로 선택해야 합니다.
- RESET하지 않으면 시계는 계속 앞으로 흐릅니다.
- 이동과 일반 상호작용은 시간 흐름을 멈추거나 초기화하지 않습니다.
- 지정된 시각에 종이 울리면 해결 연출을 시작합니다.
- 별도의 `LET TIME GO` 버튼이나 선택지는 만들지 않습니다.
- 해결 연출 중에는 RESET과 일반 입력을 차단합니다.
- 종이 울리기 직전 Echo들이 현재 Player를 바라보고, 종이 울린 뒤 하나씩 사라집니다.
- 문이 열린 뒤 추가 퍼즐 없이 엔딩 시퀀스로 연결합니다.

**결정 이유:** RESET을 강제로 빼앗지 않고 지금까지의 해결 도구를 스스로 사용하지 않는 선택을 게임플레이로 표현하기 위함입니다.

## 8. 규칙을 가르치는 방법

**상태: ✅ 확정**

- Memory Object는 최초 발견 전에는 표시하지 않습니다.
- 최초 RESET으로 특성을 발견한 뒤 Gold 시각 언어를 사용합니다.
- Echo는 설명창보다 실패 위험이 없는 첫 퍼즐로 가르칩니다.
- Echo 상호작용 실패 원인이 불명확할 때만 짧은 시각 피드백을 제공합니다.
- 일반 RPG 조작 설명은 최소화합니다.
- RESET은 회중시계 획득 시 짧게 안내합니다.
- RESET의 부작용은 Chapter 1~3에서 거의 드러내지 않습니다.
- Chapter 4부터 명확한 이상 현상을 보여줍니다.

## 후속 결정 필요

- 각 챕터의 정확한 `resetLimit`과 `echoLimit`
- Chapter 2에서 RESET 잔여 HUD를 실제로 숨길지 여부
- 레버가 유지 입력인지 한 번 작동하는 토글인지
- Echo가 Memory Object에 영향을 주는 구체적인 오브젝트 목록
- World Memory를 브라우저 저장소에 영구 저장할지 현재 플레이 세션에서만 유지할지
- Final 시계의 시작 시각과 종이 울릴 때까지의 정확한 시간
