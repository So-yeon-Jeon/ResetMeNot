# 게임 공통 규칙 결정서

이 문서는 일반적인 4방향 그리드 퍼즐 판정의 기준입니다. Reset Me Not 고유 규칙은 [고유 규칙 결정서](./GAME_IDENTITY_DECISIONS.md)를 우선합니다.

## 결정 원칙

1. 조작과 충돌은 플레이어가 예상할 수 있는 일반적인 방식을 사용합니다.
2. 같은 입력과 초기 상태는 프레임 속도와 관계없이 같은 결과를 만듭니다.
3. 실패한 행동은 게임을 멈추거나 오류를 발생시키지 않습니다.
4. 화면 연출은 판정 결과를 표현할 뿐 규칙을 변경하지 않습니다.

## 이동과 입력

- 이동은 한 번에 한 타일씩 4방향으로 처리합니다.
- 이동 애니메이션 중 들어온 방향 입력은 다음 행동 하나만 버퍼링합니다.
- 대각선 이동은 허용하지 않습니다.
- 반대 방향키가 동시에 눌리면 새 이동을 시작하지 않습니다.
- 이동 성공 여부와 관계없이 입력한 방향을 바라봅니다.
- RESET 후 Player는 레벨 데이터의 초기 방향으로 돌아갑니다.
- 벽, 닫힌 문, 상자, 맵 경계는 Player 이동을 막습니다.
- 막힌 입력은 상태를 변경하지 않으며 필요한 경우 짧은 시각·음향 피드백을 제공합니다.

## Actor 충돌

- Player와 Echo는 서로 충돌하지 않으며 같은 타일에 있을 수 있습니다.
- Echo가 있는 타일에는 새 Echo를 중복 생성하지 않습니다.
- 한 타일에는 상자를 최대 하나만 배치합니다.
- Echo는 생성된 위치에 고정되므로 일반 이동 충돌 판정에 참여하지 않습니다.

## 상호작용

- `Z`는 Player가 바라보는 앞 한 타일에 적용합니다.
- Player가 서 있는 타일은 일반 상호작용 대상으로 보지 않습니다. 압력 스위치의 점유 판정은 예외입니다.
- 한 타일에 상호작용 가능한 오브젝트를 여러 개 겹쳐 놓지 않습니다.
- 대상이 없거나 이미 처리된 오브젝트에 대한 상호작용은 상태를 바꾸지 않습니다.
- 스토리, 대화, 컷신, 소유권, 챕터 완료는 현재 Player만 실행합니다.

## 상자

- Player 앞에 상자가 있으면 같은 방향으로 한 타일 밀기를 시도합니다.
- 상자의 목적지에 벽, 닫힌 문, 다른 상자 또는 점유형 상호작용 오브젝트가 있으면 상자와 Player 모두 움직이지 않습니다. 압력 스위치는 예외로 점유할 수 있습니다.
- 당기기, 대각선 밀기, 힘 수치 계산은 사용하지 않습니다.
- Echo는 생성 이후 이동하지 않으므로 상자를 밀지 않습니다.

## 스위치와 문

- Switch는 허용된 Player, Echo 또는 Box가 점유하는 동안 활성화되는 `pressure` 방식입니다.
- Z 상호작용 방식은 Lever로 구분하며 레벨에서 `toggle` 또는 `hold`를 명시합니다.
- 여러 문 조건의 기본 조합은 `AND`이며 `OR`가 필요하면 레벨 데이터에 명시합니다.
- 조건을 잃어도 문 타일이 Player, Echo 또는 상자에 점유되어 있으면 닫히지 않습니다.
- 점유가 사라지면 조건을 다시 계산해 닫습니다.
- Actor나 상자를 강제로 밀어내거나 문과 겹친 상태로 가두지 않습니다.
- 열쇠 문과 스위치 문은 서로 다른 조건 타입으로 구분합니다.

## RESET 입력

- 회중시계 획득 전에는 R 입력에 반응하지 않고 HUD도 표시하지 않습니다.
- 이동 중 R을 누르면 현재 한 타일 이동이 끝난 직후 RESET합니다.
- RESET 연출 중에는 다른 게임 입력을 받지 않습니다.
- 성공한 이동 또는 유효한 상호작용이 있었던 Run만 RESET할 수 있습니다.
- 빈 Run, 벽에 막힌 이동, 대상 없는 상호작용만 있었던 Run에서는 RESET을 실행하지 않고 횟수도 소비하지 않습니다.
- 한도 소진 후 RESET만 비활성화하고 현재 상태의 탐색과 상호작용은 유지합니다.
- 메뉴의 Chapter Restart는 RESET 횟수에 포함하지 않으며 현재 Puzzle State 전체를 초기화합니다.

## 챕터 완료

- 통로형 출구는 현재 Player가 출구 타일에 도달하면 완료합니다.
- 조사형 출구는 레벨 데이터에 `interact` 완료 조건을 명시합니다.
- Echo가 출구에 있어도 챕터를 완료하지 않습니다.
- 완료 판정 즉시 게임 입력을 멈추고 완료 연출로 전환합니다.

## 레벨 데이터에서 반드시 정할 항목

- Switch 활성화 주체: Player, Echo, Box
- Lever 방식: `toggle` 또는 `hold`
- 여러 문 조건의 `AND` 또는 `OR`
- 열쇠 사용 시 소모 여부
- 출구 완료 방식: 타일 도달 또는 상호작용
- `resetLimit`과 `echoLimit`
- Final 시계의 시작 시각과 목표 시각
