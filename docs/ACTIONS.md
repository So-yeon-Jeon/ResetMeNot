# 게임 행동 명세

행동은 입력 장치와 게임 규칙 사이의 안정적인 인터페이스입니다. 현재 Player만 행동을 실행하며, Echo는 RESET 순간의 Player 상태를 고정해서 유지합니다.

## 행동 타입

```ts
type GameAction =
  | { type: 'move'; direction: 'up' | 'down' | 'left' | 'right' }
  | { type: 'interact' }
  | { type: 'reset' };
```

| 행동       | 기본 입력   | Player | Echo                   |
| ---------- | ----------- | ------ | ---------------------- |
| `move`     | 방향키/WASD | 가능   | 불가                   |
| `interact` | Z           | 가능   | RESET 순간 유지 상태만 |
| `reset`    | R           | 가능   | 불가                   |

`reset`은 현재 Player 상태를 Echo 스냅샷으로 남기는 세션 제어 명령입니다.

## 공통 실행 규칙

- 입력은 키가 눌린 순간 한 번의 행동으로 변환합니다.
- 이동 애니메이션 중 새 방향 입력은 다음 행동 하나만 버퍼링합니다.
- 성공한 이동 또는 유효한 상호작용 여부를 빈 Run 판정용 플래그로 기록합니다.
- 벽에 막힌 이동과 대상 없는 상호작용은 유효한 행동으로 기록하지 않습니다.
- 이동 경로와 입력 타임라인은 저장하거나 재생하지 않습니다.
- 실패는 예외를 만들지 않고 조용히 무시합니다.

## Move

### 실행 순서

1. Actor 앞 한 타일을 계산합니다.
2. 벽, 맵 경계, 닫힌 문이면 실패합니다.
3. 상자가 있으면 같은 방향으로 상자 밀기를 시도합니다.
4. 상자를 밀 수 없으면 Actor 이동도 실패합니다.
5. 통과 가능하면 Actor를 한 타일 이동합니다.
6. 점유 기반 스위치와 문 상태를 다시 계산합니다.

현재 Player와 Echo는 서로 충돌하지 않습니다. Echo는 상자를 밀지 않습니다.

## Interact

Actor가 바라보는 인접 한 타일을 대상으로 합니다. 대상이 여러 개일 수 없도록 레벨 검증 단계에서 상호작용 오브젝트 중첩을 금지합니다.

| 대상               | 결과                     |
| ------------------ | ------------------------ |
| 열쇠               | `key.state = 'pickedUp'` |
| 상호작용 대상 없음 | 상태 변경 없음           |

스위치가 Z 상호작용식인지 압력식인지는 오브젝트 타입 또는 속성으로 명시해야 하며 A/B 합의 전에는 하나로 가정하지 않습니다.

## Reset

1. 현재 Run에 성공한 이동 또는 유효한 상호작용이 있었는지 확인합니다.
2. 리셋 한도 정책을 확인합니다.
3. 행동이 있었다면 현재 Player의 위치·방향·유지 상호작용을 Echo로 생성합니다.
4. Player와 비기억 퍼즐 상태를 초기 상태로 복원합니다.
5. 한도를 소진하면 이후 RESET만 비활성화하고 현재 플레이는 유지합니다.

유효한 행동이 없는 Run에서는 RESET을 실행하지 않으며 횟수, Echo, 상태 복원, 연출 모두 발생하지 않습니다.

R키를 누르지 않고 기다리는 것은 행동이 아닙니다. Final의 전개 조건은 경과 시간과 챕터 상태로 판정합니다.

## 테스트 기준

- 네 방향 이동 성공
- 벽, 경계, 닫힌 문 이동 실패
- 상자 밀기 성공과 실패
- 행동이 있는 RESET은 현재 위치와 방향의 Echo를 생성
- 빈 Run RESET은 Echo를 생성하지 않음
- 빈 Run RESET은 횟수를 소비하거나 상태를 복원하지 않음
- 막힌 이동과 대상 없는 상호작용은 Run을 유효하게 만들지 않음
- Echo는 생성 이후 이동하지 않음
- Echo는 상자, 열쇠, 스토리 진행을 조작하지 않음

공통 판정의 기준은 [게임 규칙 결정서](./GAME_RULE_DECISIONS.md)를 따릅니다.
